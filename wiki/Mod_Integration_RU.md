# Интеграция с модом DarkSouls

Тут описано то, как разработчики других модов могут добавить требования к характеристикам персонажа (ReqParam) и скалирование урона (ParamBonus) для своего оружия, используя API мода через `Mod.Call`.

## Метод: `RegisterWeapon`

Этот метод позволяет зарегистрировать ваше оружия в глобальной таблице скейлингов мода DarkSouls. Вызывать этот метод строго рекомендуется в переопределенном методе `PostSetupContent()` вашего мода.

### Аргументы вызова

Метод принимает ровно 11 аргументов в строго заданном порядке:

| Индекс | Тип | Описание | Пример |
| :--- | :--- | :--- | :--- |
| 0 | `string` | Название вызываемого метода. Всегда `"RegisterWeapon"`. | `"RegisterWeapon"` |
| 1 | `int` | Внутренний ID вашего предмета. | `ModContent.ItemType<MySword>()` |
| 2 | `int` | Требование к Силе (Strength). | `20` |
| 3 | `int` | Требование к Ловкости (Dexterity). | `10` |
| 4 | `int` | Требование к Интеллекту (Intelligence). | `0` |
| 5 | `int` | Требование к Вере (Faith). | `0` |
| 6 | `int` | Уровень скалирования от Силы.* | `3` (Грейд B) |
| 7 | `int` | Уровень скалирования от Ловкости.* | `5` (Грейд D) |
| 8 | `int` | Уровень скалирования от Интеллекта.* | `0` (Нет) |
| 9 | `int` | Уровень скалирования от Веры.* | `0` (Нет) |
| 10 | `float` | Насыщенность скалирования (Saturation). Стандартное значение: `100f`. | `100f` |

**Внимание к аргументам 6-9 (Грейды скалирования):** Поскольку сторонние моды не имеют прямого доступа к внутреннему `enum ScalingGrade`, уровни скейлов передаются в виде целых чисел (`int`). Используйте следующую таблицу для перевода:
* `0` = Нет скалирования (-)
* `1` = S
* `2` = A
* `3` = B
* `4` = C
* `5` = D
* `6` = E

**Заметка про Насыщенность скалирования:** Это множитель который прямо увеличивает бонус от характеристик персонажа, 100f это базовое значение которое не изменяет поведение формулы бонусного урона (100%), например 150f уже увеличит бонусный урон на 50%, а 75f уже снизит урон на 25%

### Пример использования

Ниже приведен готовый пример того, как добавить поддержку мода DarkSouls в ваш мод.

```csharp
using Terraria.ModLoader;

namespace MyAwesomeMod
{
    public class MyAwesomeMod : Mod
    {
        public override void PostSetupContent()
        {
            // Пытаемся получить инстанс мода DarkSouls
            if (ModLoader.TryGetMod("DarkSouls", out Mod darkSoulsMod))
            {
                // Регистрируем параметры для кастомного меча (MyCustomSword)
                // Требования: 20 Силы, 10 Ловкости
                // Скалирование: Сила = B (3), Ловкость = D (5)
                
                object result = darkSoulsMod.Call(
                    "RegisterWeapon",
                    ModContent.ItemType<Items.MyCustomSword>(), // 1. ID предмета
                    20, 10, 0, 0,                               // 2-5. Требования (Str, Dex, Int, Fth)
                    3, 5, 0, 0,                                 // 6-9. Скейлинг (3=B, 5=D, 0=None)
                    100f                                        // 10. Saturation
                );

                // Если интеграция прошла успешно, вызов вернет true.
                // В случае ошибки вернется ArgumentException, текст которого можно вывести в лог.
                if (result is bool success && success)
                {
                    Logger.Info("Успешно добавлено скалирование DarkSouls для MyCustomSword!");
                }
                else if (result is System.ArgumentException ex)
                {
                    Logger.Error($"Ошибка при вызове RegisterWeapon в DarkSouls: {ex.Message}");
                }
            }
        }
    }
}
